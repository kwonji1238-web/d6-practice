## API 화면 규칙
- 규칙 본문(키 없는 공개 API만, 🔌 주석, API 상자, 로딩·실패 화면, 단일 HTML, `textContent`만 사용, 커밋 금지)은 `CLAUDE.md`의 "기본 화면 구조"와 "작업 규칙"을 따른다. 데이터 → 디자인 규칙(`MAP`, `applyDesign`, 🎨 대응표)은 "데이터 → 디자인 연결 방식"을 따른다. 여기에는 CLAUDE.md에 없는 이유와 세부 문구만 둔다.
- 출처 문구: 화면 하단, 🔌 API 상자 근처에 한 줄로 적는다. (왜: API 이용 약관이 출처 표기를 요청함)
  - Open-Meteo(`weather-poster.html`): "Weather data by Open-Meteo.com"
  - wheretheiss.at(`iss-clock.html`): "Data: wheretheiss.at"
  - Art Institute of Chicago(`art-theme.html`): "Art Institute of Chicago" + 작품명·작가·연도 (예: "Art Institute of Chicago · 별이 빛나는 밤 · 반 고흐 · 1889")
- 기준 시각 문구: 시차가 있는 데이터는 "실시간"이라고 쓰지 않고 기준 시각을 같이 적는다.
  - ISS: "12초 전 기준" 형식 (`timestamp`로 계산)
  - 날씨: "2026-10-21 14:00 기준" 형식 (응답의 `current.time`)
  - 갱신 실패: "마지막 성공 14:32 · 사용 오류: HTTP 429" 형식
- 명화는 `is_public_domain`이 참인 작품만 쓴다. 거짓이거나 필드가 없으면 그 작품은 건너뛰고, 쓸 작품이 없으면 "사용 오류: 공개 도메인 작품 없음"을 보여 준다.
- 이유 모음
  - 키 금지: HTML은 누구나 코드를 볼 수 있어서 키가 새어 나감
  - 🔌 한 곳 모음: 어디가 API인지 바로 찾으려고
  - API 상자: 주소를 바꾸면 화면이 바뀌는 걸 눈으로 보려고
  - 🎨 `MAP` 한 곳 모음: 디자이너가 숫자만 고쳐도 디자인이 바뀌게 하려고
  - 🎨 대응표: 어떤 데이터 값이 어떤 디자인 값이 됐는지 확인하려고
  - 실패 처리: 무료 API는 멈추거나 바뀜
  - 기준 시각: ISS·날씨는 몇 초~몇 분 전 값이라 "실시간"이면 거짓
  - 단일 HTML: 설치 없이 바로 확인하려고
  - 커밋 금지: 세이브 포인트는 내가 검사한 뒤에 찍음
- API 값이 없거나(빈 응답, 필요한 필드 없음) API가 응답하지 않으면, 화면에 "사용 오류"와 이유(예: HTTP 오류, 값 없음)를 그대로 보여 준다. 가짜·예시·임의로 만든 데이터로 화면을 채우거나 다른 API로 몰래 바꾸지 않는다. 디자인도 "그럴듯한 기본 색"으로 바뀌지 않고 중립 회색 상태로 둔다. (왜: 없는 데이터를 있는 것처럼 보여 주면 거짓 정보가 되고, 어디가 고장 났는지 알 수 없음) → 검사: `fetch` 실패·빈 응답 분기에서 하드코딩된 대체 데이터, 더미 목록, 기본 `--hue` 값을 쓰지 않나

## 추가
- ISS 위치나 날씨를 "실시간"이라고 씀 / 기준 시각을 빼먹음
- 실패 화면 없이 `fetch`만 씀 → 주소가 틀리면 하얀 화면
- API 주소를 코드 여기저기에 흩어 둠 (🔌 규칙 위반)
- 변환 숫자(기온 구간, 속도 배율)를 `applyDesign` 안에 직접 씀 → `MAP`에 모으고 `// 🎨` 이유 주석을 단다
- 요소마다 `style.color = ...`로 직접 칠함 → CSS 변수(`--hue`, `--speed`)만 바꾼다
- 데이터 색이 밝을 때 글자가 안 보임 → 명도로 글자색을 자동 전환하고 대비 4.5:1을 확인한다
- 키가 필요한 API(OpenWeatherMap 등)를 골라 와서 `YOUR_API_KEY` 자리를 남김 → 규칙 첫 줄 위반
- 갱신 실패 때 이전 값을 새 값처럼 그대로 둠 → "마지막 성공 시각"과 오류를 같이 보여 준다
- 명화의 `is_public_domain` 확인 없이 작품을 보여 줌
- 폰 폭에 `max-width: 420px`만 걸고 끝냄 → 넓은 화면에서 폰 화면이 떠 있음. `CLAUDE.md`의 "반응형 웹 규칙"대로 중단점(768/1100px)에서 레이아웃을 바꾼다 → 검사: `@media (min-width` 유무, 그림 영역에 `px` 높이 고정이 없는지
